### - Reverse Shell
Si la _reverse shell_ no proviene de la explotación inmediata de un servicio, sino de un archivo o script malicioso introducido en el sistema objetivo (como un binario malicioso, un web shell subido al servidor o un script de persistencia que se ejecuta en el arranque).
La _reverse shell_ actúa como el mecanismo instalado para mantener o recuperar el acceso al sistema.
